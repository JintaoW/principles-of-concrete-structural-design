# 第八章 钢筋混凝土构件的裂缝、变形和耐久性

## 8.1 概述

设计任何建筑物和构筑物时，必须使其满足下列各项预定的功能要求：

一、**安全性**。结构构件能够承受住在正常施工和正常使用时可能出现的各种作用，以及在偶然事件发生时及发生后，仍能保持必要的整体稳定性。

二、**适用性**。在正常使用时，结构构件具有良好的工作性能，不出现过大的变形和过宽的裂缝。

三、**耐久性**。在正常的维护下，结构构件具有足够的耐久性能，不发生锈蚀和风化现象。

安全、适用和耐久，是结构可靠的标志，总称为**结构的可靠性**。

耐久性问题开始时表现为对结构构件外观和使用功能的影响，到一定阶段上可能引发承载力方面的问题，使结构构件出现突然的破坏。

## 8.2 裂缝宽度验算

按照其形成原因，裂缝分为两大类：**一类是荷载引起的裂缝**；**另一类是由变形因素引起的裂缝**，如材料收缩、温度变化、钢筋锈蚀膨胀以及地基不均匀沉降等原因引起的裂缝。工程实践中，**结构物的裂缝属于变形因素为主的约占80%**，属于荷载为主引起的约占20%。非荷载引起的裂缝十分复杂，目前主要是通过构造措施（如加强配筋、设变形缝等）进行控制。本节讨论的为荷载引起的正截面裂缝验算。

## 8.3 受弯构件挠度验算

变形验算主要指**受弯构件的挠度验算**。结构或结构构件受力后将在截面上产生内力，并使截面产生变形。截面上的材料抵抗内力的能力就是截面承载力；抵抗变形的能力就是截面刚度。对于承受弯矩*M*的截面来说，抵抗截面转动的能力，就是**截面弯曲刚度**。**截面弯曲刚度就是使截面产生单位曲率需要施加的弯矩值**。

#### 3. 长期刚度*B*的计算

#### 4. 受弯构件挠度的计算

**钢筋混凝土受弯构件截面的抗弯刚度随弯矩增大而减小**。在实际计算中，对于承受均布荷载的简支梁，考虑到支座附近弯矩较小区段虽然刚度较大，但它对全梁变形的影响不大，故一般取同号弯矩区段内弯矩最大截面的抗弯刚度作为该区段的抗弯刚度。对于简支梁即取最大正弯矩截面按式8-25计算的截面刚度，并以此作为全梁的抗弯刚度。对于带悬挑的简支梁、连续梁或框架梁，则取最大正弯矩截面和最小负弯矩截面的刚度，分别作为相应弯矩区段的刚度。这就是挠度计算中通称的“**最小刚度原则**”。

构件刚度分布图确定以后，即可按结构力学的方法计算钢筋混凝土受弯构件的挠度。

受弯构件挠度除弯曲变形外，还受剪切变形的影响。**一般情况下，这种剪切变形的影响很小，可忽略不计**。但是对受荷较大的工字形、T形截面等薄腹构件，应酌情考虑。

当式8-11不能满足时，**最有效的措施是增加截面高度**；当设计上构件截面尺寸不能加大时，可**考虑增加纵向受拉钢筋截面面积或提高混凝土强度等级**；对某些构件还可以**充分利用纵向受压钢筋对长期刚度的有利影响**，**在构件受压区配置一定数量的受压钢筋**。此外，**采用预应力混凝土构件**也是提高受弯构件刚度的有效措施。

## 8.4 耐久性设计

**混凝土结构的耐久性是指在正常维护条件下，在预计的使用时期内，在指定的工作环境中保证结构满足既定的功能要求。**所谓正常维护，是指不因耐久性问题而需花过高维修费用。耐久性设计涉及面广，影响因素多，主要考虑以下几个方面：一、环境分类，针对不同环境，采取不同的措施；二、耐久性等级或结构寿命分类等；三、耐久性计算对设计寿命或既存结构的寿命作出预计；四、保证耐久性的构造措施和施工要求等。

## 8.5 小结

一、钢筋混凝土构件的裂缝、变形和耐久性问题，属于结构的正常使用状态，对其进行验算的目的是保证其适用性和耐久性。

二、工程中出现的裂缝有荷载裂缝与非荷载裂缝。

三、裂缝的控制等级分为三级：一级指正常使用阶段严格要求不出现裂缝；二级指正常使用阶段一般要求不出现裂缝；三级指正常使用阶段允许出现裂缝。

四、钢筋混凝土受弯构件的裂缝宽度是按荷载效应准永久组合并考虑长期作用影响进行验算。

五、钢筋混凝土受弯构件的挠度是按荷载效应的准永久组合计算短期刚度*B<sub>s</sub>*，并考虑长期荷载的影响计算长期刚度*B*进行验算。

六、耐久性设计目前主要是针对结构物所处的工作环境，对混凝土的材料提出了保证耐久性的要求和钢筋的保护措施。
