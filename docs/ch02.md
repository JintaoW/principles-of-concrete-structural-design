# 第二章 混凝土结构设计方法

## 2.1 结构可靠度

### 2.1.1 结构上的作用、作用效应及结构抗力

#### 1. 结构上的作用和作用效应

结构上的作用包括施加在结构上的集中力或分布力（称为直接作用，习惯称荷载），以及引起结构外加变形或约束变形的各种因素（称为间接作用）。

按随时间的变异划分：永久作用、可变作用、偶然作用

按随空间的变化划分：固定作用、自由作用

按结构的反应特点划分：静态作用、动态作用

按作用有无限值划分：有界作用、无界作用

直接作用或间接作用作用在结构构件上，由此对结构产生内力和变形（如轴力、剪力、弯矩、扭矩及挠度、转角和裂缝等），称为作用效应。当为直接作用（即荷载）时，其效应也称为荷载效应，通常用S表示。

#### 2. 结构上的环境影响和效应

环境影响是指温度、湿度及其变化以及二氧化碳、氧、盐、酸等环境因素对结构的影响。环境影响对结构产生的效应主要是针对材料性能的降低，它与材料本身有密切关系。多数情况下，环境影响的效应涉及化学的和生物的损害，其中环境湿度是最关键的因素。

目前主要根据材料特点，通过环境对结构影响程度的分级（轻微、轻度、中度、严重等）等方法进行定性描述。

按时间的变异性划分：永久影响、可变影响、偶然影响

#### 3. 结构抗力

结构抗力R是指整个结构或结构构件承受作用效应（即内力和变形）和环境影响的能力，如构件的承载能力、刚度、抗裂度及材料的抗劣化能力等。

为确定可变作用等取值而选用的时间参数，称为设计基准期。GB50068-2018《建筑结构可靠性设计统一标准》规定房屋建筑结构的设计基准期为50年。

### 2.1.2 结构的功能要求及结构可靠度

《建筑结构可靠性设计统一标准》规定在设计使用年限内结构应满足下列功能要求：

1)  在正常施工和正常使用时，能承受可能出现的各种作用（包括荷载及外加变形或约束变形）

2)  在正常使用时，保持良好的使用性能，如不发生过大的变形或过宽的裂缝等

3)  在正常维护下，具有足够的耐久性能，如结构材料的风化、腐蚀和老化不超过一定限度等

4)  发生火灾时，在规定的时间内可保持足够的承载力

5)  当发生爆炸、撞击、人为错误等偶然事件时，结构能保持必需的整体稳固性，不出现与起因不相称的破坏后果，防止出现结构的连续倒塌

上述1、4、5项属于结构的安全性；2项关系到结构的适用性；3项为结构的耐久性。

安全性、适用性和耐久性总称为结构的可靠性，也就是结构在规定的时间内、在规定的条件下完成预定功能的能力。

结构可靠度是指结构在规定的时间内、在规定的条件下完成预定功能的概率，即结构可靠度是其可靠性的概率度量。

设计使用年限是指设计规定的结构或结构构件不需要进行大修即可按其预定目的使用的年限，即结构在规定的条件下所应达到的使用年限。设计使用年限并不等同于建筑结构的实际寿命或耐久年限，当结构的实际使用年限超过设计使用年限后，其可靠度可能较设计时的预期值减小，但结构仍可继续使用或经大修后可继续使用。若使结构保持一定的可靠度，则设计使用年限取得越长，结构所需的截面尺寸或所需要的材料用量就越大。

### 2.1.3 结构的安全等级

结构设计时，应根据房屋的重要性采用不同的可靠度水准。《统一标准》用结构的安全等级来表示房屋的重要性程度。其中，大量的一般房屋列入中间等级，重要的房屋提高一级，次要的房屋降低一级。

## 2.2 荷载和材料强度

结构所承受的荷载在一定范围内变动，同样地，材料的实际强度也在一定范围内波动。因此结构设计时，所取用的荷载值和材料强度值应采用概率统计方法来确定。

### 2.2.1 荷载标准值的确定

#### 1. 荷载的统计特性

（1）永久荷载G

建筑结构中的屋面、楼面、墙体、梁柱等构件自重重力及找平层、保温层、防水层等自重重力都是永久荷载，通常称为恒荷载，其值不随时间变化或变化很小。统计结果表明，永久荷载这一随机变量符合正态分布。

（2）可变荷载Q

建筑结构的楼面活荷载、风荷载和雪荷载等属于可变荷载，其数值随时间变化。

民用房屋楼面活荷载一般分为持久性活荷载（如家具产生的荷载）和临时性活荷载（人员临时聚会形成的荷载）两种。民用房屋楼面活荷载（包括持久性和临时性活荷载）及风荷载和雪荷载的概率分布均可认为是极值Ⅰ型分布。

#### 2. 荷载标准值

荷载标准值是建筑结构按极限状态设计时采用的荷载基本代表值。该值理论上应为结构在使用期间，在正常情况下，可能出现的具有一定保证率的偏大荷载值。现行相关规范为GB 50009-2012《建筑结构荷载规范》

（1）永久荷载标准值*G<sub>k</sub>*

永久荷载（恒荷载）标准值*G<sub>k</sub>*可按结构设计规定的尺寸和《荷载规范》规定的材料重度（或单位面积的自重）平均值确定，一般相当于永久荷载概率分布的平均值。

（2）可变荷载标准值*Q<sub>k</sub>*

《荷载规范》规定，办公楼、住宅楼面均布活荷载标准值*Q<sub>k</sub>*均为2.0 kN/m<sup>2</sup>。

风荷载标准值由建筑物所在地的基本风压乘以风压高度变化系数、风载体型系数和风振系数确定。

雪荷载标准值由建筑物所在地的基本雪压乘以屋面积雪分布系数确定。

各类可变荷载标准值及各种材料重度（或单位面积的自重）可由《荷载规范》查取。

### 2.2.2 材料强度标准值的确定

#### 1. 材料强度的变异性及统计特性

统计资料表明，钢筋强度的概率分布符合正态分布，混凝土强度分布也基本符合正态分布。

#### 2. 材料强度标准值

材料强度标准值是材料强度概率分布中具有一定保证率的偏低的材料强度值。钢筋和混凝土的强度标准值是钢筋混凝土结构按极限状态设计时采用的材料强度基本代表值。

（1）钢筋强度标准值

《混凝土结构设计规范》2015年版规定，钢筋的强度标准值应具有不小于95%的保证率。对有明显屈服点的热轧钢筋，取国家钢筋标准规定的屈服强度特征值作为屈服强度标准值，钢筋强度特征值的保证率大于95%；对无明显屈服点的钢筋、钢丝及钢绞线，取国家钢筋标准规定的极限抗拉强度作为极限强度标准值，但结构设计时对消除应力钢丝和钢绞线取0.85*σ<sub>b</sub>*作为条件屈服点，对中强度预应力钢丝和螺纹钢筋有所调整。对于结构的抗倒塌设计，均采用极限强度标准值。

（2）混凝土强度标准值

混凝土强度标准值为具有95%保证率的强度值。

## 2.3 极限状态设计法

### 2.3.1 结构的极限状态

整个结构或结构的一部分超过某一特定状态就不能满足设计规定的某一功能要求，此特定状态称为该功能的极限状态。极限状态实质上是区分结构可靠和失效的界限。极限状态分为三类：承载能力极限状态、正常使用极限状态和耐久性极限状态。

#### 1. 承载能力极限状态

该状态对应于结构或结构构件达到最大承载能力或达到不适于继续承载的变形。承载能力极限状态为结构或结构构件达到允许的最大承载功能的状态。

承载能力极限状态主要考虑有关结构安全性的功能，出现的概率应该很低。对于任何承载的结构或构件，都需按承载能力极限状态进行设计。

结构或结构构件出现下列状态之一时，应认为超过了承载能力极限状态：

- 结构构件或连接因所受应力超过材料强度而破坏，或因过度变形而不适于继续承载

- 整个结构或结构的一部分作为刚体失去平衡（如倾覆等）

- 结构转变为机动体系

- 结构或结构构件丧失稳定（如压屈等）

- 结构因局部破坏而发生连续倒塌

- 地基丧失承载能力而破坏

- 结构或结构构件的疲劳破坏

#### 2. 正常使用极限状态

该状态对应于结构或结构构件达到正常使用的某项规定限值。正常使用极限状态主要考虑有关结构适用性的功能，对财产和生命的危害较小，故出现概率允许稍高一些，但仍应予以足够的重视。通常对结构构件先按承载能力极限状态进行承载能力计算，然后根据使用要求按正常使用极限状态进行变形、裂缝宽度或抗裂等验算。

当结构或结构构件出现下列状态之一时，应认为超过了正常使用极限状态：

- 影响正常使用或外观的变形，如吊车梁变形过大使吊车无法平稳行驶，梁挠度过大影响外观

- 影响正常使用的局部损坏，如水池开裂漏水无法正常使用

- 影响正常使用的振动，如机器振幅超过正常使用要求的限值

- 影响正常使用的其他特定状态，如相对沉降量过大

#### 3. 耐久性极限状态

该状态对应于结构或结构构件在环境影响下出现的劣化（材料性能随时间的逐渐衰减）达到耐久性的某项规定限值或标志的状态。结构耐久性极限状态设计，应使结构构件出现耐久性极限状态标志或限值的年限不小于其设计使用年限。

当结构或结构构件出现以下状态之一时，应认为超过了耐久性极限状态：

- 影响承载能力和正常使用的材料性能劣化

- 影响耐久性的裂缝、变形、缺口、外观、材料削弱等

- 影响耐久性的其他特定状态

### 2.3.2 结构的设计状况

建筑结构设计时，应根据结构在施工和使用中的环境条件和影响，区分四种设计状况：

#### 持久设计状况

在结构使用过程中一定出现，其持续期很长的状况。持续期一般与设计使用年限为同一数量级。

#### 短暂设计状况

在结构施工和使用过程中出现概率较大，而与设计使用年限相比，持续时间很短的状况。

#### 偶然设计状况

在结构使用过程中出现概率很小，且持续时间很短的状况。

#### 地震设计状况

结构使用过程中遭受地震作用时的状况。

这四种设计状况均应进行承载能力极限状态设计，以确保结构的安全性。对持久设计状况，尚应进行正常使用极限状态设计；对短暂设计状况和地震设计状况，可根据需要进行正常使用极限状态设计；对于偶然设计状况，可不进行正常使用极限状态设计。

### 2.3.3 结构的功能函数和极限状态方程

当功能函数中仅包括作用效应S和结构抗力R两个基本变量时，可得

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle Z = g\left( {R,S} \right) = R - S \)</span></span><span class="eq-no">(2-6)</span>
</div>

当Z&gt;0时，结构处于可靠状态；当Z&lt;0时，结构处于失效状态；当Z=0时，结构处于极限状态。

### 2.3.4 结构可靠度的计算

#### 1. 结构的失效概率*p<sub>f</sub>*

结构功能函数Z=R-S&lt;0的概率称为结构构件的失效概率，记作*p<sub>f</sub>*。

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {p_f} = \Phi \left( { - \frac{{{\mu _Z}}}{{{\sigma _Z}}}} \right) = 1 - \Phi \left( {\frac{{{\mu _Z}}}{{{\sigma _Z}}}} \right) \)</span><span class="arithmatex">\( \displaystyle {p_f} = \Phi \left( { - \frac{{{\mu _Z}}}{{{\sigma _Z}}}} \right) = 1 - \Phi \left( {\frac{{{\mu _Z}}}{{{\sigma _Z}}}} \right) \)</span></span><span class="eq-no">(2-9, 2-10)</span>
</div>

式中*μ<sub>Z</sub>*为功能函数Z的均值，*σ<sub>z</sub>*为标准差，Ф(·)为标准正态分布函数。

用失效概率度量结构可靠性具有明确的物理意义，能较好地反映问题的实质。但*p<sub>f</sub>*的计算比较复杂，因而国际标准和我国标准目前都采用可靠度指标*β*来度量结构的可靠性。

#### 2. 结构构件的可靠指标*β*

\(1\) 可靠指标*β*

令

<div class="eq">
  <span class="eq-body"><img src="/images/ch02/image4.png" style="width:10px" alt=""><span class="arithmatex">\( \displaystyle \beta  = \frac{{{\mu _Z}}}{{{\sigma _Z}}} = \frac{{{\mu _R} - {\mu _S}}}{{\sqrt {\sigma _R^2 + \sigma _S^2} }} \)</span></span><span class="eq-no">(2-11)</span>
</div>

则式（2-9）可写为

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {p_f} = \Phi \left( { - \frac{{{\mu _Z}}}{{{\sigma _Z}}}} \right) = \Phi \left( { - \beta } \right) \)</span></span><span class="eq-no">(2-12)</span>
</div>

可见，*β*越大，*p<sub>f</sub>*就越小，即结构越可靠，故*β*称为可靠指标。由式(2-11)可见*β*直接与基本变量的平均值和标准差有关，而且还可以考虑基本变量的概率分布类型，所以它能反映影响结构可靠度的各主要因素的变异性，这是传统的安全系数所未能做到的。

\(2\) 设计可靠指标\[*β*\]

设计规范所规定的、作为设计结构或结构构件时所应达到的可靠指标，称为设计可靠指标\[*β*\]，也称目标可靠指标。结构构件正常使用极限状态的设计可靠指标，根据其作用效应的可逆程度宜取0~1.5。对建筑结构构建耐久性极限状态的设计可靠指标\[*β*\]，宜根据其可逆程度取1.0~2.0。

目前除对少数十分重要的结构，如原子能反应堆、海上采油平台等直接按上述方法外，一般结构仍采用极限状态设计表达式进行设计。

## 2.4 极限状态设计表达式

长期以来，人们已习惯采用基本变量的标准值（如荷载标准值、材料强度标准值等）和分项系数（如荷载分项系数、材料分项系数等）进行结构构件设计。考虑到这一习惯，并为了应用上的简便，规范在设计验算点处，将极限状态方程转化为以基本变量标准值和分项系数形式表达的极限状态设计表达式。这意味着设计表达式中的各分项系数是根据结构构件基本变量的统计特性，以结构可靠度的概率分析为基础经优选确定的，它们起着相当于设计可靠指标\[*β*\]的作用。

- *S<sub>d</sub>* — 承载能力极限状态下作用组合的效应设计值：对持久设计状况和短暂设计状况应按作用的基本组合计算，对地震设计状况应按作用的地震组合计算

- *R<sub>d</sub>* — 结构构件抗力设计值

- *R*(·) — 结构构件的抗力函数

- *γ<sub>Rd</sub>* — 结构构件的抗力模型不定性系数：静力设计取1.0，对不确定性较大的结构构件根据具体情况取大于1.0的数值；抗震设计应用承载力抗震调整系数*γ<sub>RE</sub>*代替*γ<sub>Rd</sub>*

- *a<sub>k</sub>* — 几何参数的标准值，当几何参数的变异性对结构性能有明显的不利影响时，应增减一个附加值

- *f<sub>c</sub>* — 混凝土的强度设计值

- *f<sub>s</sub>* — 钢筋的强度设计值

二、对二维、三维混凝土结构构件，当按弹性或弹塑性方法分析并以应力形式表达时，可将混凝土应力按区域等代成内力设计值，按式(2-13)进行计算；按弹塑性方法分析或采用多轴强度准则设计时，应根据材料强度平均值计算承载力函数。

三、对偶然作用下的结构进行承载能力极限状态设计时，式(2-13)中的作用效应设计值*S<sub>d</sub>*按偶然组合计算。结构重要性系数*γ<sub>0</sub>*取不小于1.0的数值；当计算结构构件的承载力函数时，式(2-14)中混凝土、钢筋的强度设计值*f<sub>c</sub>*、*f<sub>s</sub>*改用强度标准值*f<sub>ck</sub>*、*f<sub>yk</sub>*（或*f<sub>pyk</sub>*）。当进行结构防倒塌验算时，其作用宜考虑结构相应部分倒塌冲击引起的动力效应；在计算承载力函数时，混凝土强度取标准值，普通钢筋强度取极限强度标准值*f<sub>stk</sub>*，预应力筋强度取极限强度标准值*f<sub>ptk</sub>*并考虑锚具的影响；*a<sub>k</sub>*宜考虑偶然作用下结构倒塌对结构几何参数的影响；必要时可考虑材料强度在动力作用下的强度和脆性，并取相应的强度特征值。

四、整个结构或其一部分作为刚体失去静力平衡的承载能力极限状态设计，应符合下式要求：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle \gamma _0S_{d,dst}\leqslant S_{d,stb} \)</span></span><span class="eq-no">(2-15)</span>
</div>

- *S<sub>d,dst</sub>* — 不平衡作用效应的设计值

- *S<sub>d,stb</sub>* — 平衡作用效应的设计值

#### 2. 荷载组合的效应设计值*S<sub>d</sub>*

对持久和短暂设计状况，应采用基本组合

对偶然设计状况，应采用偶然组合

对地震设计状况，应采用作用效应的地震组合

一、基本组合

荷载组合的效应设计值*S<sub>d</sub>*按下式确定：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d=S\left( \sum_{i\geqslant 1}{\gamma _{G_i}G_{ik}+\gamma _PP+\gamma _{Q_1}\gamma _{L_1}Q_{1k}+\sum_{j>1}{\gamma _{Q_j}\psi _{c_j}\gamma _{L_j}Q_{jk}}} \right) \)</span></span><span class="eq-no">(2-16)</span>
</div>

- *S*(·) — 作用组合的效应函数

- *G<sub>ik</sub>* — 第*i*个永久作用的标准值

- $\gamma _{G_i}$ — 第*i*个永久作用的分项系数

- *P* — 预应力作用的有关代表值

- $\gamma _P$ — 预应力作用的分项系数

- *Q<sub>1k</sub>* — 第1个可变作用的标准值

- $\gamma _{Q_1}$ — 第1个可变作用的分项系数

- $\gamma _{L_1}$ — 第1个考虑结构设计使用年限的荷载调整系数

- *Q<sub>jk</sub>* — 第*j*个可变作用的标准值

- $\gamma _{Q_j}$ — 第*j*个可变作用的分项系数

- $\psi _{c_j}$ — 第*j*个可变作用的组合值系数

- $\gamma _{L_j}$ — 第*j*个考虑结构设计使用年限的荷载调整系数

上述基本组合中的设计值仅适用于荷载与荷载效应为线性的情况。

二、偶然组合

对于偶然组合，荷载组合的效应设计值按下式确定：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d=\sum_{i\geqslant 1}{S_{G_{ik}}+S_P+S_{A_d}+\left( \psi _{f1}\text{或}\psi _{q1} \right) S_{Q_{1k}}+\sum_{j>1}{\psi _{qj}S_{Q_{jk}}}} \)</span></span><span class="eq-no">(2-17)</span>
</div>

- $S_{A_d}$ — 偶然作用设计值的效应

- $\psi _{f1}$ — 第1个可变作用的频遇值系数

- $\psi _{q1}$、$\psi _{qj}$ — 第1个和第*j*个可变作用的准永久值系数

偶然荷载的代表值不乘分项系数，因为偶然荷载标准值的确定本身带有主观的臆测因素。

#### 3. 荷载分项系数、可变荷载的组合值系数

\(1\) 荷载分项系数*γ<sub>G</sub>*、*γ<sub>Q</sub>*

荷载标准值是结构在使用期间、在正常情况下可能遇到的具有一定保证率的偏大荷载值。统计资料表明，各类荷载标准值的保证率并不相同，所以引入荷载分项系数予以调整。GB 50068 2018《建筑结构可靠性统一标准》暂时按永久荷载和可变荷载两大类分别给出荷载分项系数。

GB 50009-2012《建筑结构荷载规范》规定荷载分项系数应按下列规定采用：

1)  永久荷载分项系数*γ<sub>G</sub>*

当永久荷载效应对结构不利（使结构内力增大）时，取1.3；对结构有利（使结构内力减小）时，取1.0。

2)  可变荷载分项系数*γ<sub>Q</sub>*

一般情况下应取1.5；对工业建筑楼面结构，当活荷载标准值大于4 kN/m<sup>2</sup>时，从经济效果考虑，应取1.3。

\(2\) 荷载设计值

荷载分项系数与荷载标准值的乘积，称为荷载设计值。

\(3\) 荷载组合值系数$\psi _{ci}$，荷载组合值$\psi _{ci}Q_{ik}$

当结构上作用几个可变荷载时，各可变荷载最大值在同一时刻出现的概率很小，若设计中仍采用各荷载效应设计值叠加，则可能造成结构可靠度不一致，因而要对可变荷载设计值再乘以调整系数。荷载组合值系数$\psi _{ci}$就是这种调整系数，称为可变荷载的组合值$\psi _{ci}Q_{ik}$。注意：$\psi _{ci}$是关于可变荷载的。

#### 4. 材料分项系数、材料强度设计值

为充分考虑材料的离散性和施工中不可避免的偏差带来的不利影响，再将材料强度标准值除以一个大于1的系数，即得材料强度设计值，相应的系数为材料分项系数。注意：材料强度设计值比其标准值低！

### 2.4.2 正常使用极限状态设计表达式

#### 1 可变荷载的频遇值和准永久值

荷载标准值是在设计基准期内最大荷载的意义上确定的，它没有反映荷载作为随机过程而具有随时间变异的特性。当结构按正常使用极限状态的要求进行设计时，应从不同的要求来选择荷载的代表值。

可变荷载有四种代表值：标准值、组合值、频遇值和准永久值。其中，标准值为基本代表值，其他三值可由标准值分别乘以相应系数（小于1.0）而得。注意：组合值、频遇值和准永久值均小于标准值。

可变荷载的频遇值是指在设计基准期内，其超越的总时间约为规定的较小比率或超越频率为规定频率的荷载值。它相当于结构上时而出现的较大荷载值，但总小于荷载标准值。

可变荷载的准永久值是指在设计基准期内，其超越的总时间约为设计基准期一半的荷载值，即在设计基准期内经常作用的荷载值（接近于永久荷载）。

#### 2. 正常使用极限状态设计表达式

对于正常使用极限状态，结构构件应分别按荷载效应的标准组合、频遇组合、准永久组合或标准组合并考虑长期作用影响，采用下列极限状态设计表达式：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d\leqslant C \)</span></span><span class="eq-no">(2-19)</span>
</div>

- *S<sub>d</sub>* — 正常使用极限状态的荷载组合的效应设计值（如变形、裂缝宽度、应力等的效应设计值）

- *C* — 结构构件达到正常使用要求所规定的变形、裂缝宽度和应力等的限值

一、标准组合的效应设计值*S<sub>d </sub>*:

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d=\sum_{j=1}^m{S_{G_jk}+S_P+S_{Q_1k}+\sum_{i=2}^n{\psi _{ci}S_{Q_ik}}} \)</span></span><span class="eq-no">(2-20)</span>
</div>

- $S_{G_jk}$ — 第*j*个永久作用标准值的效应

- $S_P$ — 预应力作用有关代表值的效应

- $S_{Q_1k}$ — 第1个可变作用标准值的效应

- $\psi _{ci}$ — 第*i*个可变作用组合值系数

- $S_{Q_ik}$ — 第*i*个可变作用标准值的效应

这种组合主要用于当一个极限状态被超越时将产生严重的永久性损害的情况，即标准组合一般用于不可逆正常使用极限状态。

二、频遇组合的效应设计值*S<sub>d </sub>*:

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d=\sum_{j=1}^m{S_{G_jk}+S_P+\psi _{f1}S_{Q_1k}+\sum_{i=2}^n{\psi _{qi}S_{Q_ik}}} \)</span></span><span class="eq-no">(2-21)</span>
</div>

- $S_{G_jk}$ — 第*j*个永久作用标准值的效应

- $S_P$ — 预应力作用有关代表值的效应

- $\psi _{f1}$ — 第1个可变作用的频遇值系数

- $S_{Q_1k}$ — 第1个可变作用标准值的效应

- $\psi _{qi}$ — 第*i*个可变作用准永久值系数

- $S_{Q_ik}$ — 第*i*个可变作用标准值的效应

频遇组合是指永久荷载标准值、预应力作用效应、主导可变荷载的频遇值与伴随可变荷载的准永久值的效应组合。这种组合主要用于当一个极限状态被超越时将产生局部损害、较大变形或短暂振动等情况，即频遇组合一般用于可逆正常使用极限状态。

三、准永久组合的效应设计值*S<sub>d </sub>*:

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle S_d=\sum_{j=1}^m{S_{G_jk}+S_P+\sum_{i=1}^n{\psi _{qi}S_{Q_ik}}} \)</span></span><span class="eq-no">(2-22)</span>
</div>

- $S_{G_jk}$ — 第*j*个永久作用标准值的效应

- $S_P$ — 预应力作用有关代表值的效应

- $\psi _{qi}$ — 第*i*个可变作用准永久值系数

- $S_{Q_ik}$ — 第*i*个可变作用标准值的效应

准永久组合主要用在当荷载的长期效应是决定性因素时的一些情况。

正常使用极限状态要求的设计可靠指标\[*β*\]较小，因而设计时对荷载不用分项系数，对材料强度取标准值。

进行正常使用极限状态设计时，应考虑荷载长期效应的影响，即应考虑荷载的准永久组合，有时尚应考虑荷载的频遇组合。

#### 3. 正常使用极限状态验算规定

一、对结构构件进行抗裂验算时，应按荷载标准组合的效应设计值进行计算，其计算值不应超过规范规定的相应限值。

二、结构构件的裂缝宽度，对混凝土构件按荷载准永久组合的效应设计值并考虑长期作用影响进行计算；对预应力混凝土构件，按荷载标准组合的效应设计值并考虑长期作用影响进行计算；构件的最大裂缝宽度不应超过规范规定的最大裂缝宽度限值。

三、受弯构件的最大挠度，混凝土构件应按荷载准永久组合的效应设计值，预应力混凝土构件应按荷载标准组合的效应设计值，并均应考虑荷载长期作用的影响进行计算，其计算值不应超过规范规定的挠度限值。

## 2.5 小结

一、结构可靠度是结构可靠性（安全性、适用性和耐久性的总称）的概率度量。结构安全性的概率度量称为结构安全度，它是结构可靠度中最重要的内容。

设计基准期为确定可变作用等取值而选用的时间参数；设计使用年限表示结构在规定的条件下所应达到的使用年限。两者均不等同于结构的实际寿命或耐久年限。

二、作用于建筑物上的荷载分为永久荷载、可变荷载、偶然荷载。永久荷载服从正态分布；可变荷载服从极值Ⅰ型分布；偶然荷载的概率模型与其种类有关。永久荷载采用标准值作为代表值；可变荷载采用标准值、组合值、频遇值和准永久值作为代表值，其中标准值是基本代表值，其他代表值都可在标准值的基础上乘以相应的系数求得。

三、对承载能力极限状态的荷载效应组合，应采用基本组合（持久、短暂和地震设计状况）或偶然组合（偶然设计状况）；对正常使用极限状态的荷载效应组合，按荷载的持久性和不同的设计要求采用三种组合：标准组合、频遇组合和准永久组合。对持久设计状况，应进行正常使用极限状态设计；对短暂设计状况，可根据需要进行正常使用极限状态设计。

四、钢筋和混凝土强度的概率分布属正态分布。钢筋和混凝土的强度设计值是用各自的强度标准值除以相应的材料分项系数而得到的。正常使用极限状态设计时，材料强度一般取标准值。承载能力极限状态设计时，对持久、短暂和地震设计状态，一般取用材料强度设计值；对偶然设计状态（如抗倒塌设计），混凝土取强度标准值，钢筋取极限强度标准值。

五、结构的极限状态分为三类：承载能力极限状态、正常使用极限状态和耐久性极限状态。以相应于结构各种功能要求的极限状态作为结构设计依据的设计方法，称为极限状态设计法。在极限状态设计法中，若以结构的失效概率或可靠指标来度量结构可靠度，并且建立结构可靠度与结构极限状态之间的数学关系，这就是概率极限状态设计法。

六、概率极限状态设计表达式与以往的多系数极限状态设计表达式在形式上很相似，但二者存在本质上的区别。前者的各项系数是根据结构构件基本变量的统计特性，以可靠度分析经优选确定的，它们起着相当于设计可靠指标\[*β*\]的作用；而后者采用的各种安全系数主要是根据工程经验确定的。
