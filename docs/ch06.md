# 第六章 钢筋混凝土受扭构件承载力计算

## 6.1 概述

扭转是结构承受的五种基本受力状态之一。钢筋混凝土结构在扭矩作用下，根据扭矩形成的原因，可分为两类：一是平衡扭转；二是协调扭转或称为附加扭转。若结构的扭矩是由荷载产生的，其扭矩可根据平衡条件求得，与构件的抗扭刚度无关，这种扭转称之为平衡扭转。超静定结构中由于变形的协调使截面产生的扭转，称为协调扭转或附加扭转。

## 6.2 受扭构件的试验研究

纯扭构件截面上的最大剪应力、主拉应力和主压应力均相等。混凝土抗拉强度*f*<sub>t</sub>低于受剪强度*f<sub>τ</sub>*，受剪强度*f<sub>τ</sub>*低于抗压强度*f*<sub>c</sub>。试验表明：无筋矩形截面混凝土构件在扭矩作用下，首先在截面长边中点附近最薄弱处产生一条45°角方向的斜裂缝，然后迅速以螺旋形向相邻两个面延伸，最后形成一个三面开裂一面受压的空间扭曲破坏面，使结构立即破坏，破坏带有突然性，具有典型脆性破坏性质。

通常在构件中配置纵筋和箍筋来承受主拉应力，承受扭矩作用效应。钢筋混凝土构件截面的开裂扭矩比相应的素混凝土构件约高10%~30%。

钢筋混凝土构件的破坏特征主要与配筋数量有关：少筋构件和超筋构件的破坏都属于脆性破坏，在工程设计中应予以避免；适筋构件属于延性破坏，在工程设计中应普遍应用。

试验表明：受扭构件配置钢筋不能有效地提高受扭构件的开裂扭矩，但能够较大幅度地提高受扭构件破坏时的极限扭矩值。

## 6.3 受扭构件承载力计算

### 6.3.1 纯扭构件承载力计算

#### 1. 矩形截面钢筋混凝土纯扭构件

纯扭构件扭曲截面计算包括两个方面：一是结构受扭的开裂扭矩计算；二是结构受扭承载力计算。

一、开裂扭矩计算

结构混凝土即将出现裂缝时，由于混凝土极限拉应变很小，因此钢筋的应力也很小，它对结构提高开裂荷载作用不大。因此，开裂扭矩计算时可忽略钢筋的影响。

开裂扭矩值计算公式为：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {T_{\mathrm{cr}}} = 0.7{f_{\mathrm{t}}}{W_{\mathrm{t}}} \)</span></span><span class="eq-no">(6-4)</span>
</div>

- *f*<sub>t</sub> — 混凝土抗拉强度设计值

- *W*<sub>t</sub> — 截面受扭塑性抵抗矩。对于矩形截面${W_{\mathrm{t}}} = \frac{{{b^2}}}{6}\left( {3h - b} \right)$，*b*和*h*为矩形截面的短边边长和长边边长

二、矩形截面钢筋混凝土纯扭构件承载力计算

钢筋混凝土纯扭构件的抗扭承载力由混凝土的抗扭承载力和箍筋与纵筋的抗扭承载力两部分构成。

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle T \le 0.35{f_{\mathrm{t}}}{W_{\mathrm{t}}} + 1.2\sqrt \zeta  {f_{\mathrm{yv}}}\frac{{{A_{\mathrm{st1}}}{A_{\mathrm{cor}}}}}{s} \)</span></span><span class="eq-no">(6-8)</span>
</div>

- *T* — 扭矩设计值

- *f*<sub>t</sub> — 混凝土的抗拉强度设计值

- *W*<sub>t</sub> — 截面的抗扭塑性抵抗矩

- *f*<sub>yv</sub> — 箍筋的抗拉强度设计值，按教材附表2-3中*f*<sub>y</sub>值采用，当数值大于360N/mm<sup>2</sup>时应取360N/mm<sup>2</sup>

- *A*<sub>st1</sub> — 受扭计算中沿截面周边配置的箍筋单肢截面面积

- *s* — 箍筋的间距

- *A*<sub>cor</sub> — 核心截面部分的面积，*A*<sub>cor</sub>= *b*<sub>cor</sub>*h*<sub>cor</sub>

- *ζ* — 抗扭纵筋与箍筋的配筋强度比，$\zeta  = \frac{{{f_{\mathrm{y}}}{A_{\mathrm{stl}}}s}}{{{f_{\mathrm{yv}}}{A_{\mathrm{st1}}}{u_{\mathrm{cor}}}}}$\[式6-9\]，*ζ*值不应小于0.6，其值大于1.7时，取1.7。

- *A*<sub>stl</sub> — 对称布置在截面中的全部抗扭纵筋的截面面积

- *f*<sub>y</sub> — 抗扭纵筋的抗拉强度设计值

- *u*<sub>cor</sub> — 核心截面部分的周长，*u*<sub>cor</sub>=2(*b*<sub>cor</sub>+*h*<sub>cor</sub>)，*b*<sub>cor</sub>和*h*<sub>cor</sub>分别为箍筋内表面计算的核心截面部分的短边和长边尺寸

#### 2. T形和工字形截面纯扭构件承载力计算

T形和工字形截面纯扭构件承受扭矩*T*时，可将截面划分为腹板、受压翼缘及受拉翼缘三个矩形块，将总的扭矩*T*按各矩形块的受扭塑性抵抗矩分配给各矩形块承担，各矩形块承担的扭矩为：

\(1\) 腹板 ${T_{\mathrm{w}}} = \frac{{{W_{\mathrm{tw}}}}}{{{W_{\mathrm{t}}}}}T$ (6-10)

\(2\) 受压翼缘 $T_{\mathrm{f}}^{'} = \frac{{W_{\mathrm{tf}}^{'}}}{{{W_{\mathrm{t}}}}}T$ (6-11)

\(3\) 受拉翼缘 ${T_{\mathrm{f}}} = \frac{{{W_{\mathrm{tf}}}}}{{{W_{\mathrm{t}}}}}T$ (6-12)

- *W*<sub>t</sub> — 工字形截面的受扭塑性抵抗矩，${W_{\mathrm{t}}} = {W_{\mathrm{tw}}} + W_{\mathrm{tf}}^{'} + {W_{\mathrm{tf}}}$

- *W*<sub>tw</sub>，*W<sup>’</sup>*<sub>tf</sub>，*W*<sub>tf</sub> — 分别为腹板、受压翼缘、受拉翼缘矩形块受扭塑性抵抗矩，分别为${W_{\mathrm{tw}}} = \frac{{{b^2}}}{6}\left( {3h - b} \right)$，$W_{\mathrm{tf}}^{'} = \frac{{h{{_{\mathrm{f}}^{'}}^2}}}{2}\left( {b_{\mathrm{f}}^{'} - b} \right)$，${W_{\mathrm{tf}}} = \frac{{h_{\mathrm{f}}^2}}{2}\left( {{b_{\mathrm{f}}} - b} \right)$\[式6-13，式6-14，式6-15\]

#### 3. 箱形截面钢筋混凝土纯扭构件

箱形截面受扭承载力公式是在矩形截面受扭承载力公式（式6-8）的基础上得到的：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle T \le 0.35{\alpha _{\mathrm{h}}}{f_{\mathrm{t}}}{W_{\mathrm{t}}} + 1.2\sqrt \zeta  {f_{\mathrm{yv}}}\frac{{{A_{\mathrm{st1}}}{A_{\mathrm{cor}}}}}{s} \)</span></span><span class="eq-no">(6-16)</span>
</div>

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {\alpha _{\mathrm{h}}} = \frac{{2.5{t_{\mathrm{w}}}}}{{{b_{\mathrm{h}}}}} \)</span></span><span class="eq-no">(6-17)</span>
</div>

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {W_{\mathrm{t}}} = \frac{{b_{\mathrm{h}}^2}}{6}\left( {3{h_{\mathrm{h}}} - {b_{\mathrm{h}}}} \right) - \frac{{{{\left( {{b_{\mathrm{h}}} - 2{t_{\mathrm{w}}}} \right)}^2}}}{6}\left[ {3{h_{\mathrm{w}}} - \left( {{b_{\mathrm{h}}} - 2{t_{\mathrm{w}}}} \right)} \right] \)</span></span><span class="eq-no">(6-18)</span>
</div>

- *α*<sub>h</sub> — 箱形截面壁厚系数，当*α*<sub>h</sub>&gt;1.0时，取1.0

- *t*<sub>w</sub> — 箱形截面壁厚，其值不应小于*b*<sub>h</sub>/7

- *h*<sub>h</sub>，*b*<sub>h</sub> — 箱形截面的长边和短边尺寸

- *h*<sub>w</sub> — 箱形截面腹板高度

箱形截面公式中ζ值仍按式6-9计算，*ζ*值不应小于0.6，其值大于1.7时，取1.7。

### 6.3.2 弯剪扭构件承载力计算

#### 1. 矩形截面弯剪扭构件承载力计算

在弯矩、剪力和扭矩作用下，钢筋混凝土结构的破坏形态及其承载力既与结构弯矩、剪力和扭矩的比值，即与扭弯比（$\varphi _{\mathrm{m}}=\frac{T}{M}$）和扭剪比（$\varphi _{\mathrm{v}}=\frac{T}{Vb}$）有关；还与结构的截面形状、尺寸、配筋形式、数量和材料强度等因素有关。钢筋混凝土构件在弯剪扭作用下有三种破坏类型：弯型破坏、剪扭型破坏、扭型破坏。

矩形截面剪扭构件的承载力计算按以下步骤进行：

一、按抗剪承载力计算需要的抗剪箍筋*nA*<sub>sv1</sub>/*s*<sub>v</sub>

构件的抗剪承载力按以下公式计算：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle V\leqslant 0.7f_{\mathrm{t}}bh_0\left( 1.5-\beta _{\mathrm{t}} \right) +f_{\mathrm{yv}}\frac{nA_{\mathrm{sv1}}}{s_{\mathrm{v}}}h_0 \)</span></span><span class="eq-no">(6-24)</span>
</div>

对矩形截面独立梁，当集中荷载在支座截面中产生的剪力占该截面总剪力75%以上时，用下式计算：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle V\leqslant \frac{1.75}{\lambda +1}\left( 1.5-\beta _{\mathrm{t}} \right) f_{\mathrm{t}}bh_0+f_{\mathrm{yv}}\frac{nA_{\mathrm{sv1}}}{s_{\mathrm{v}}}h_0 \)</span></span><span class="eq-no">(6-25)</span>
</div>

式中1.5 ≤ *λ* ≤ 3.0，$\beta _{\mathrm{t}}=\frac{1.5}{1+0.2\left( \lambda +1 \right) \frac{VW_{\mathrm{t}}}{Tbh_0}}$\[式6-26\]，1.5 ≤ *β*<sub>t</sub> ≤ 3.0。

二、按抗扭承载力计算需要的抗扭箍筋*A*<sub>st1</sub>/*s*<sub>t</sub>

构件的抗扭承载力按以下公式计算：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle T\leqslant 0.35\beta _{\mathrm{t}}f_{\mathrm{t}}W_{\mathrm{t}}+1.2\sqrt{\zeta}\frac{f_{\mathrm{yv}}A_{\mathrm{st1}}A_{\mathrm{cor}}}{s_{\mathrm{t}}} \)</span></span><span class="eq-no">(6-27)</span>
</div>

式中系数*β*<sub>t</sub>应区别抗剪计算出现的两种情况，分别按式6-23或式6-26计算

三、按照叠加原则计算抗剪扭总的箍筋用量$A_{\mathrm{sv1}}^{*}/s$

由以上抗剪和抗扭计算分别确定所需的箍筋数量后，还要按照叠加原则计算总的箍筋需要量。叠加原则是指将抗剪计算所需要的箍筋用量中的单侧箍筋用量*A*<sub>sv1</sub>/*s*<sub>v</sub>（如采用双肢箍筋，*A*<sub>sv1</sub>/*s*<sub>v</sub>即为需要量*nA*<sub>sv1</sub>/*s*<sub>v</sub>中的一半；如采用四肢箍筋，*A*<sub>sv1</sub>/*s*<sub>v</sub>即为需要量的1/4）与抗扭所需的单肢箍筋用量*A*<sub>st1</sub>/*s*<sub>t</sub>相加，从而得到每侧箍筋总的需要量为：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle A_{\mathrm{sv1}}^{*}/s=A_{\mathrm{sv1}}/s_{\mathrm{v}}+A_{\mathrm{st1}}/s_{\mathrm{t}} \)</span></span><span class="eq-no">(6-28)</span>
</div>

2\. T形和工字形截面弯剪扭构件承载力计算

T形和工字形截面弯剪扭结构承载力计算，除弯矩作用按受弯构件进行受弯承载力计算外，结构受剪扭承载力计算按如下方法进行：

一、按截面完整性准则，将T形和工字形截面按图6-7划分为若干矩形块，分别求出各矩形截面受扭塑性抵抗矩*W*<sub>t<em>i</em></sub>，然后求和$W_{\mathrm{t}}=\sum{W_{\mathrm{t}i}}$。

二、截面扭矩分配：全截面扭矩*T*按划分各矩形截面的受扭塑性抵抗矩进行分配，按式6-13~式6-15计算。

三、配筋计算。对于腹板：考虑同时承受剪力和扭矩，当需要考虑剪扭相关性时，按*V*及*T*<sub>w</sub>由受剪扭结构承载力计算公式6-24及式6-27或式6-25及式6-27进行配筋计算。对于受压及受拉翼缘：不考虑翼缘承受剪力，按*T’*<sub>f</sub>及*T*<sub>f</sub>由受纯扭结构承载力计算公式6-8进行配筋计算。

最后将计算所得的纵筋及箍筋截面面积分别叠加。

### 6.3.4 受扭构件计算公式的适用条件及构造要求

1\. 截面限制条件

《混凝土结构设计规范》对钢筋混凝土剪扭构件，规定截面限制条件如下：

当*h*<sub>w</sub>/*b* ≤ 4时

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle \frac{V}{bh_0}+\frac{T}{0.8W_{\mathrm{t}}}\leqslant 0.25\beta _{\mathrm{c}}f_{\mathrm{c}} \)</span></span><span class="eq-no">(6-35a)</span>
</div>

当*h*<sub>w</sub>/*b* ≥ 4时

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle \frac{V}{bh_0}+\frac{T}{0.8W_{\mathrm{t}}}\leqslant 0.20\beta _{\mathrm{c}}f_{\mathrm{c}} \)</span></span><span class="eq-no">(6-35b)</span>
</div>

当4&lt;*h*<sub>w</sub>/*b*&lt;6时，线性内插

- *h*<sub>w</sub>— 截面的腹板高度，对于矩形截面取有效高度*h<sub>0</sub>*；对于T形截面取有效高度减去翼缘高度；对于工字形截面取腹板净高度。

若计算时不满足式6-35要求，则加大构件截面尺寸或提高混凝土强度等级。

#### 2. 构造配筋

一、构造配筋界限

钢筋混凝土构件承受的剪力及扭矩相当于结构混凝土即将开裂时的剪力及扭矩值的界限状态，称为构造配筋界限。

《混凝土结构设计规范》规定对剪扭构件构造配筋的界限如下：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle \frac{V}{{b{h_0}}} + \frac{T}{{{W_{\mathrm{t}}}}} \le 0.7{f_{\mathrm{t}}} \)</span></span><span class="eq-no">(6-36)</span>
</div>

二、最小配筋率

钢筋混凝土受扭构件能够承受相当于素混凝土受扭构件所能承受的极限承载力时，相应的配筋率称为受扭构件钢筋的最小配筋率。受扭构件的最小配筋率包括构件箍筋最小配筋率及纵筋最小配筋率。

结构在剪扭共同作用下，结构受剪及受扭箍筋最小配筋率为：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {\rho _{sv,\min }} = \frac{{{A_{sv,\min }}}}{{bs}} = 0.28\frac{{{f_{\mathrm{t}}}}}{{{f_{\mathrm{yv}}}}} \)</span></span><span class="eq-no">(6-37)</span>
</div>

对于结构在剪扭共同作用下，受扭纵筋的最小配筋率为：

<div class="eq">
  <span class="eq-body"><span class="arithmatex">\( \displaystyle {\rho _{tl,\min }} = \frac{{{A_{stl,\min }}}}{{bh}} = 0.6\frac{{{f_{\mathrm{t}}}}}{{{f_{\mathrm{y}}}}}\sqrt {\frac{T}{{Vb}}} \)</span></span><span class="eq-no">(6-38)</span>
</div>

其中当$\frac{T}{{Vb}} > 2$时取2。

结构设计时，纵筋最小配筋率应取受弯及受扭纵筋最小配筋率叠加值。受扭纵筋应沿截面周边对称布置。

#### 3. 钢筋的构造要求

受扭箍筋应采用封闭式，设置在截面的周边；受扭箍筋的弯钩搭接长度按构造规定。当采用复合箍筋时，位于截面内部的箍筋不应计入受扭所需的箍筋截面面积。受扭纵筋应对称设置于截面的周边；受扭纵筋伸入支座长度应按充分利用强度的受拉钢筋考虑。

## 6.4 小结

一、结构扭转分为两种类型：一是平衡扭转；二是协调扭转或称为附加扭转。

二、截面在剪力作用下将产生等值的主拉、主压应力及最大剪应力，由于$\left( {{\tau  \mathord{\left/  {\vphantom {\tau  {{f_{\mathrm{t}}}}}} \right.  \kern-1.2pt} {{f_{\mathrm{t}}}}}} \right) > \left( {{\tau  \mathord{\left/  {\vphantom {\tau  {{f_\tau }}}} \right.  \kern-1.2pt} {{f_\tau }}}} \right) > \left( {{\tau  \mathord{\left/  {\vphantom {\tau  {{f_{\mathrm{c}}}}}} \right.  \kern-1.2pt} {{f_{\mathrm{c}}}}}} \right)$，因此混凝土的开裂是拉应力达到抗拉强度（或拉应变达到极限拉应变）引起的。因此，受扭构件采用承受主拉应力的螺旋式配筋或采用纵筋及箍筋的配筋形式。受扭构件按配筋数量分为适筋、超筋（或部分超筋）及少筋构件。前者为延性破坏，后二者是脆性破坏；前者应用于结构，后二者在结构设计中应避免。

三、矩形截面纯扭构件计算，包括受扭开裂扭矩、承载力计算，结构满足承载力要求时，尚应满足裂缝宽度限制及构造要求。

四、矩形截面结构在弯矩、剪力和扭矩共同作用下，其受力状态及破坏形态十分复杂，它与结构的截面形状、尺寸、配筋形式、数量及材料强度有关；还与结构的扭弯比${\varphi _{\mathrm{m}}} = {T \mathord{\left/  {\vphantom {T M}} \right.  \kern-1.2pt} M}$和扭剪比${\varphi _{\mathrm{v}}} = {T \mathord{\left/  {\vphantom {T {\left( {Vb} \right)}}} \right.  \kern-1.2pt} {\left( {Vb} \right)}}$有关。

对于矩形截面弯、扭构件承载力计算：分别按受弯、受扭构件承载力计算，纵筋数量采用叠加方法，箍筋由受扭计算方法。

对于矩形截面弯剪扭构件承载力计算：分别按受弯、受剪和受扭构件承载力计算，纵筋数量采用叠加方法；按受剪和受扭承载力计算时应考虑混凝土承载力的相互影响*β*<sub>t</sub>，分别决定箍筋数量并采用叠加方法。

五、T形和工字形截面弯、剪扭构件除按受弯承载力计算外，根据“截面完整性”准则，将T形和工字形截面划分为数个矩形截面块，各截面承受的扭矩按各矩形截面受扭塑性抵抗矩进行分配。

主矩形截面进行受剪、受扭承载力计算；次矩形截面不进行受剪承载力计算，仅按纯扭构件进行受扭承载力计算。

T形和工字形截面弯、剪扭构件进行承载力计算后，纵向受力钢筋按其数量和位置进行叠加；箍筋按其数量和位置进行叠加。

六、钢筋混凝土纯扭、剪扭构件承载力计算时，应注意基本公式的适用条件及最小配筋率的要求。
